# Android App Icons (Basic to Latest Android Versions)

This folder contains high-resolution, anti-aliased PNG icons for the **Bharath Blood Donor** mobile app, styled and scaled for every Android OS version from basic legacy devices to the latest Android 15+.

---

## 📱 Icon Density & Size Matrix

| Folder / File Name | Pixel Size | Android Compatibility |
| --- | --- | --- |
| **`res/mipmap-ldpi/`** | **36 x 36 px** | Android 4.0 - 5.0 (Basic Low DPI phones) |
| **`res/mipmap-mdpi/`** | **48 x 48 px** | Android 5.0 - 6.0 (Medium DPI phones) |
| **`res/mipmap-hdpi/`** | **72 x 72 px** | Android 7.0 - 8.0 (720p HD screens) |
| **`res/mipmap-xhdpi/`** | **96 x 96 px** | Android 9.0 - 10 (1080p Full HD screens) |
| **`res/mipmap-xxhdpi/`** | **144 x 144 px** | Android 11 - 13 (Pixel, Samsung, OnePlus) |
| **`res/mipmap-xxxhdpi/`** | **192 x 192 px** | Android 14 - 15+ (4K Quad HD Flagships) |
| **`adaptive_foreground_432x432.png`** | **432 x 432 px** | Android 8.0+ Adaptive Masking Layer |
| **`play_store_icon_512x512.png`** | **512 x 512 px** | Google Play Console Submission |
| **`apple_app_store_icon_1024x1024.png`** | **1024 x 1024 px** | Apple App Store Connect Submission |

---

## 🛠️ How to Use
- To replace icons in any Android Studio or React Native project, copy the contents of the `res/` folder directly into `android/app/src/main/res/`.
